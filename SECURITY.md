# Security Policy

## Supported Versions

Blueprint Modular is under active development. Security updates are
applied to the latest published release of `@blueprint-modular/core`
and to the `master` branch. Earlier versions are not maintained.

| Version            | Supported          |
| ------------------ | ------------------ |
| Latest release     | :white_check_mark: |
| Older releases     | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public
GitHub issues, pull requests, or discussions.

Instead, report them privately through one of the following channels:

- **GitHub Security Advisories** — use the
  ["Report a vulnerability"](https://github.com/Blueprint-Master/blueprint-modular/security/advisories/new)
  button on this repository (preferred).
- **Email** — `security@blueprint-modular.com` <!-- TODO: replace with a monitored address -->

When reporting, please include where relevant:

- the affected component or surface (React package, Python surface, MCP server);
- a description of the vulnerability and its potential impact;
- the steps required to reproduce it;
- any proof-of-concept code, if available.

## Response Process

- **Acknowledgement** — we aim to acknowledge a report within 5 business days.
- **Assessment** — we will evaluate the report and determine severity and scope.
- **Resolution** — confirmed vulnerabilities will be addressed in a timely
  manner, with priority scaled to severity. We will keep you informed of progress.
- **Disclosure** — we follow a coordinated disclosure process. Please allow us
  reasonable time to release a fix before any public disclosure.

## Scope

This policy covers the Blueprint Modular component system, its published
packages, and the MCP server at `mcp.blueprint-modular.com`. Issues affecting
applications generated by Blueprint Maker should be reported through the
relevant Blueprint Maker channel.
