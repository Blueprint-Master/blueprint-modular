Module Veille

Module de veille informationnelle : agrégation de sources, alertes, tableaux de bord. Idéal pour suivre l'actualité, des flux RSS ou des métriques.

Fonctionnalités prévues

  • Configuration de sources (RSS, APIs, scrapers)
  • Alertes et notifications (seuils, mots-clés)
  • Tableau de bord de veille (flux, résumés, filtres)
Note — Ce module est prévu dans la roadmap. Voir Ce qu'il reste à faire.
