Module Analyse de document

Upload, extraction et analyse de documents (texte, PDF) avec IA. Idéal pour synthèses, Q&A sur des docs, extraction de données structurées.

Fonctionnalités prévues

  • Upload de fichiers (PDF, TXT, DOCX)
  • Extraction de texte et structure
  • Analyse IA : résumé, questions-réponses, entités, tableaux
