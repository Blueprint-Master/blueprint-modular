write

Affiche un texte brut ou la représentation d'un objet Python.

Référence API

FonctionBPM
write()bpm.write()

Exemple

import bpm

bpm.write("Texte brut ou objet Python.")
bpm.write(42)
bpm.write({"cle": "valeur"})
